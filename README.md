# Time Tracker

Time Tracker is a Frappe app for employee timers, correction approvals, and ERPNext/HRMS payroll integration.

## Compatibility

- Frappe, ERPNext, and HRMS must all use the same major version.
- Supported major versions: **15.x and 16.x**.
- Python: **3.10 or newer**, subject to the requirements of your Bench version.
- Frappe Helpdesk is optional. When Helpdesk is absent, Project and Task tracking 
continue to work and the Ticket selector remains unavailable.
